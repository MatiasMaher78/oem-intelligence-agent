removing its documents. Read the [product overview](../../README.md),
[current architecture](../ARCHITECTURE.md), [decision index](../DECISIONS.md) and

A delivery document can remain a useful technical reference while its test
counts, model recommendation, Git state or "future work" describe only that
milestone. These records are not runtime model instructions or authorization
for new tools, model calls, scheduling or commercial actions.

## Original demo and learning material

The [original architecture](../ARCHITECTURE.md#original-demo) describes the isolated
six-case SQL/Python demo and optional two-tool SDK reviewer. Its 90-day/unverified
OEM selection, HIGH/MEDIUM/LOW priorities and seven-read baseline differ from the
current 27-piece inclusive 60-90-day pipeline and five-tool agent.

[Learning labs](../LEARNING_LABS.md) preserve optional exercises around that old
demo. Proposed third tools, paid SDK experiments, extra cases or schedules are
exercises, not implemented current features or permission to enable them.
The [publishing checklist](../PUBLISHING_CHECKLIST.md) remains a reusable safety
template, not a dated assertion that every publication step is pending.

## Reading recorded evidence

Stage 5.5 closed with 359 automated tests, five scripted scenarios and twelve
negative controls. Later local report regression reached 367 tests; it is not a
new hosted CI result. The current evaluation reference distinguishes those scopes.
Real E1 is approved with skill 1.0.1; E2/E5 are partial/not approved with skill
1.0.2 and remain closed without further runs or optimization.

Ignored `runs/`, `reviews/` and database paths identify local verification
artifacts; they are not bundled public inputs. Use the current Quick Start and
offline evaluator for a fresh checkout, and follow explicit prerequisites in
advanced examples. Historical token/latency measurements do not predict current
provider availability, remaining quota, billing state or model quality.

No historical document grants permissions beyond the existing contracts/harness.
The runtime loads only the packaged [OEM evidence skill](../../oem_agent/skills/oem-evidence-review/SKILL.md).
